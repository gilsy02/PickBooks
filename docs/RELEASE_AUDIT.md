## B. 점검 결과
### 즉시 수정함
1. [치명] 릴리스 AndroidManifest에 INTERNET 권한 없음 → 설치본에서 YES24 검색·표지 불가. 수정(8982edd)
2. [법적] 샘플 데이터에 실제 책(아몬드, 여행의 이유) 문장이라며 지어낸 문장이 들어 있었음 → 삭제

### 출시 전 반드시 (차단 요소)
3. [보안·출시] 릴리스가 debug 키로 서명됨 → 업로드 키 생성, GitHub Secrets로 서명. 키 분실 시 업데이트 불가
4. [출시] 사용자가 YES24 키를 직접 입력하는 구조 → 일반 사용자 불가, 애플 심사 통과 어려움. 서버 프록시(예: Cloudflare Workers 무료)가 키를 보관하는 구조로 변경 필요
5. [법적] YES24 약관 원문 미확인: 앱 배포 허용, 책 정보·표지 URL 영구 저장 허용, 출처 표기 방식, 키 1개로 다수 사용자 서비스 허용 여부 → 원문 확인 또는 YES24 문의
6. [법적] 개인정보처리방침 필요 (데이터를 서버로 안 보내도 스토어가 요구). 카메라·사진 사용, 기기 내 저장, YES24로 검색어 전송 명시
7. [법적] 아이 이름 등 아동 정보: 기기에만 저장되어 운영자 수집은 아님. 대상 연령은 "성인(부모)"으로 신고해 가족 정책 적용 회피, 방침에 명시
8. [저작권] 아이 방 그림(assets/images/kids_room.jpg)은 컨셉 이미지에서 잘라 씀 → 원본 출처·권리 확인(직접 생성/구매 여부). 불명확하면 교체
9. [저작권] 데미안 샘플 문장은 번역본 문장(번역 저작권) → 출시판에서는 샘플 문장 교체 또는 샘플 데이터 제거
10. [출시] 앱 아이콘이 Flutter 기본 아이콘 → 픽북스 아이콘 제작
11. [라이선스] 글꼴(OFL)·오픈소스 패키지 고지 화면 없음 → 프로필에 "오픈소스 라이선스" 추가

### 권장
12. [보안] YES24 키를 SharedPreferences(평문)에 저장 → 4번 프록시로 바꾸면 해소. 유지 시 flutter_secure_storage
13. [보안] Android 자동 백업(allowBackup 기본값)으로 기록이 구글 드라이브 백업에 포함됨 → 방침에 명시하거나 제외 규칙
14. [상표] "픽북스/PickBooks" 동일 앱은 검색에서 못 찾음. 상표 등록 여부는 KIPRIS에서 직접 확인 필요
15. [용량] APK 41.6MB 중 글꼴 23MB → 글꼴 서브셋
16. [정확성] YES24 응답 필드 실기기 미검증

## C. 문제 없음으로 본 항목
- 공개 저장소에 비밀값 없음 (키·토큰 검색 결과 없음), 커밋 작성자 noreply
- 외부 통신은 HTTPS만 (http 표지 주소는 https로 변환)
- 서버로 보내는 개인 데이터 없음 (YES24에 검색어·ISBN만 전송)
- 대상 SDK 36으로 구글 요건 충족
