# 진행 기록

## 2026-11-22 · v0.1.0 (AI 없는 첫 버전)
결정(사용자): 개발 방식은 Claude 판단, AI 기능 제외, 빠른 것부터, 아이폰도 지원.
선택: Flutter (안드로이드·아이폰 한 코드). 데이터는 기기 안(SharedPreferences, JSON) 저장.

### 완료
- 공통: 픽북스/키즈 전환, 하단 탭, 버건디·크림 색, 글꼴(고운바탕, 나눔펜, 나눔붓; 모두 OFL)
- 내 서재: 전면 책장(표지)·일반 책장(책등), 상태별 선반, 꾹 눌러 끌어서 옮기기(칸 이동·순서 변경), 진행률 배지, 공유, 정렬
- 책 담기: 직접 입력(표지 사진, 쪽수, 분류, 칸 선택)
- 책 상세: 상태 변경, 읽은 쪽 슬라이더(끝까지 가면 완독 칸으로), 별점, 정보 수정, 삭제
- 기록: 문장 목록, 노트 모양 넘겨 보기(스와이프), 문장·내 생각(손글씨체) 담기/수정
- 홈: 이번 주 추천 5권(읽고 싶은 책 중 주마다 순서 변경, 기록 기반 규칙 문구), 이어 읽기, 서재 검색
- 프로필: 통계, 픽북스가 본 나(규칙 기반), JSON 내보내기, 샘플 복원, 전체 삭제
- 키즈: 아이별 서재 추가/이름 변경/삭제, 읽은 책/읽어 볼 책, 검색·정렬·좋아요 필터, 또 읽었어요(횟수·날짜), 머릿속 영역 태그
- 키즈 성장: 12개월 막대 그래프·평균선, 연속 주 수, 머릿속 지도(누르면 영역별 책)
- 키즈 추천: 연한 영역 안내, 다시 읽어 줄 책, 읽어 볼 책
- 빌드: GitHub Actions에서 안드로이드 APK, 아이폰 서명 없는 IPA 자동 생성

### 준비 중 (다음 단계)
| 기능 | 막힌 이유 | 방안 |
|---|---|---|
| 책 검색·표지 자동 | 도서 API 키 필요 | 알라딘 TTB 키 발급 후 연결 |
| 바코드 | 위와 같음(ISBN → 책 정보) | mobile_scanner + 알라딘 ItemLookUp |
| 사진으로 문장 담기 | 문자 인식 | Google ML Kit 한국어 OCR (기기 내, 무료) |
| 커플 공유 | 서버 필요 | Supabase/Firebase 동기화 (계정·공유 서재) |
| 아이폰 설치 | 애플 서명 필요 | 무료 Apple ID+Sideloadly(7일마다 재서명) / 개발자 계정 연 99달러(TestFlight) / 웹앱 |
| AI 추천·분석 | 제외(사용자 결정) | 규칙 기반으로 자리 마련해 둠 |
