# 픽북스 개인정보처리방침

시행일: 2026년 ○월 ○일 (출시일로 수정)

픽북스(이하 "앱")는 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 지킵니다.

## 1. 수집하는 정보와 저장 위치
앱은 운영자의 서버로 개인정보를 수집하거나 전송하지 않습니다. 이용자가 입력한 아래 정보는 **이용자의 기기 안에만** 저장됩니다.

| 정보 | 예시 | 저장 위치 |
|---|---|---|
| 서재 기록 | 책 제목, 읽은 쪽, 별점, 상태 | 기기 |
| 담은 문장과 생각 | 문장, 메모 | 기기 |
| 키즈 책장 | 아이 이름(별명 가능), 읽은 날짜, 영역 태그 | 기기 |
| 표지 사진 | 이용자가 고른 사진의 기기 내 경로 | 기기 |
| 이름(닉네임) | 앱에 표시할 이름 | 기기 |

앱을 지우면 위 정보도 함께 지워집니다. 운영자는 이 정보를 열람할 수 없습니다.

## 2. 외부로 전송되는 정보
- **도서 검색**: 책을 검색하거나 바코드를 찍으면 검색어 또는 ISBN이 도서 정보 제공을 위해 픽북스 중계 서버(Cloudflare)를 거쳐 예스24 Open API로 전송됩니다. 이 정보에는 이용자를 식별하는 정보가 포함되지 않으며, 운영자는 검색 기록을 저장하지 않습니다. (중계 서버는 같은 검색 결과를 최대 하루 동안 임시 저장할 수 있습니다.)
- **표지 이미지**: 책 표지 이미지를 예스24 이미지 서버에서 불러옵니다.
- **공유·내보내기**: 이용자가 직접 공유 버튼을 누른 경우에만, 이용자가 고른 앱으로 서재 목록 또는 기록 파일이 전달됩니다.

## 3. 기기 권한
| 권한 | 목적 | 거부 시 |
|---|---|---|
| 카메라 | 책 바코드 인식 | 바코드 담기만 쓸 수 없음 |
| 사진 | 표지 사진 고르기 | 표지 사진만 넣을 수 없음 |
| 인터넷 | 도서 검색, 표지 불러오기 | 검색 불가, 직접 입력은 가능 |

## 4. 백업
안드로이드의 자동 백업 기능이 켜져 있으면, 기기 설정에 따라 앱 데이터가 이용자 본인의 구글 계정 백업에 포함될 수 있습니다. 이는 구글이 이용자 계정에 제공하는 기능이며 운영자는 접근할 수 없습니다.

## 5. 아동의 정보
앱은 부모(성인)가 자녀의 독서 기록을 관리하도록 만든 앱이며, 만 14세 미만 아동을 대상으로 하지 않습니다. 키즈 책장에 입력한 아이 이름 등은 부모의 기기에만 저장되고 운영자에게 전송되지 않습니다. 실명 대신 별명을 써도 됩니다.

## 6. 이용자의 권리
모든 정보는 이용자의 기기에 있으므로, 이용자는 앱의 [프로필 > 모든 기록 지우기] 또는 앱 삭제로 언제든 정보를 지울 수 있습니다.
