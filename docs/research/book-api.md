# 도서 API 조사 (2026-11-22)

제약: 작업 환경에서 aladin.co.kr, docs.google.com, developers.kakao.com 접속이 막혀 원문을 직접 열지 못함. 아래는 검색 결과에 인용된 문구 기준. 신뢰도 최대 '중'.

## 알라딘 TTB 키
| 항목 | 내용 | 출처 | 신뢰도 |
|---|---|---|---|
| 정체 | 알라딘 Open API 호출용 개인 인증키(`ttbkey` 파라미터 필수) | aladin.co.kr/ttb/apiguide.aspx | 중 |
| 발급 | 알라딘 회원가입 후 발급 | velog 블로그 | 하 |
| 한도 | "1일 5000회로 제한. 이상은 ttb@aladin.co.kr 문의" (페이지 최종수정 2007.9.1, 현재와 다를 수 있음) | apiguide.aspx | 중 |
| API | ItemSearch(검색), ItemLookUp(ISBN 조회), ItemList(신간·베스트) | 비공식 라이브러리 문서 | 중 |
| 데이터 | 표지(Cover=Big 등), 쪽수 itemPage(subInfo), 카테고리 | velog | 하 |
| 무료 여부 | 유료 안내는 찾지 못함. 명시적 '무료' 문구도 원문 미확인 | - | 미확인 |
| 미확인 | 상업 이용, 출처 표기 의무, 표지 사용 조건, 저장 허용, 앱 사용 허용, 승인 시간 | - | - |

## 대안
| API | 요약 | 신뢰도 |
|---|---|---|
| 카카오 책 검색 | 무료 일 3만 건(운영 측 포럼 답변). 상업 이용 가능, 재판매·AI 입력 금지. DB 영구 저장 불가, 일시 캐시만 | 중 |
| 네이버 책 검색 | 종료 보도(원문 공지 미확인) | 중 |
| 국립중앙도서관 ISBN 서지 | cert_key 필요, ISBN·제목 검색. 무료·한도 미확인 | 중 |

## 판단
- 개인·커플 사용 규모(하루 수십 회)면 알라딘 5000회, 카카오 3만 건 모두 한도 문제 없음.
- 카카오는 '영구 저장 불가' 조항이 서재 앱(책 정보 저장)과 충돌 소지. 알라딘을 주력으로 두고 원문 약관 확인 필요.
- 앱은 도서 검색을 교체 가능한 구조로 만들고, 키 없이도 직접 입력으로 동작하게 함.
