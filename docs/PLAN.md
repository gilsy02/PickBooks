# 픽북스(PickBooks) 개발 계획 v0.1 (2026-11-22, 승인 대기)

## 0. 목표
컨셉 이미지 6장의 화면과 기능을 삼성 갤럭시(안드로이드)에서 실제로 쓰는 앱으로 구현.

## 1. 화면 분석 (이미지 → 기능)
| # | 화면 | 기능 | 필요한 외부 요소 |
|---|------|------|------------------|
| 1 | 내 서재 | 전면/일반 책장 전환, 상태별 선반(읽는 중·읽고 싶은·완독), 진행률 %, 드래그로 선반 이동, 공유, 정렬 | 책 표지·쪽수 데이터 |
| 1 | 책 담기 | 검색 · 바코드(ISBN) · 직접 입력 | 도서 검색 API, 바코드 인식(기기 내 ML Kit) |
| 2 | 홈 추천 | 매주 5권 추천, 내 기록을 근거로 한 추천 이유 | AI(LLM) + 서버 |
| 3 | 담은 문장 | 문장 + 내 생각(손글씨체), 날짜, 좌우 스와이프, 사진으로 문장 담기, 나만 보기 | 문자인식 OCR(기기 내 ML Kit, 한국어) |
| 4 | 키즈 책장 | 아이별 서재, 읽은 책/읽어 볼 책, 검색·필터, 다시 읽은 횟수, 좋아요 | 도서 API |
| 5 | 키즈 성장 | 달마다 읽은 책 그래프, 평균, 연속 주 수, 머릿속 5영역(나·감정·관계·생각과 세상·자라는 마음) | 책→영역 분류(AI) |
| 6 | 픽북스가 본 나 | 월간 독자 유형 요약, 끌리는 책·읽는 방식·취향과 기록 사이·요즘의 결 | AI(LLM) + 서버 |

## 2. 기술 선택 (권고)
- 앱: Flutter(Dart). 이유: (1) 이 작업 환경에서 웹으로 화면을 띄워 이미지와 대조 검증 가능, (2) 추후 iOS 확장 가능.
  대안: Kotlin + Jetpack Compose(안드로이드 전용, 성능 약간 우위, 이 환경에선 화면 검증 불가).
- 저장: 기기 내 DB(Drift/SQLite). "나에게만 보여요"와 맞음. 클라우드 동기화는 3단계.
- 도서 데이터: 알라딘 Open API(TTB 키, 무료). 표지·쪽수·분류 제공 → 진행률·취향 분석에 필요. 보조: 카카오 책 검색.
- 바코드·OCR: Google ML Kit(기기 내, 무료, 오프라인).
- AI: Claude API. 키를 앱에 넣으면 유출되므로 작은 서버(Cloudflare Workers 또는 Supabase Edge Function)에서 호출.
- 빌드: 이 컨테이너는 Android SDK 다운로드가 막혀 있음(dl.google.com 차단 확인). GitHub Actions에서 APK를 빌드 → 휴대폰에 직접 설치.

## 3. 단계
| 단계 | 내용 | 산출물 |
|------|------|--------|
| 1. 뼈대·디자인 | 색·글꼴·공통 컴포넌트, 하단 탭, 픽북스/키즈 전환 | 화면 껍데기, 웹 스크린샷 대조 |
| 2. 내 서재 | 책장 2종, 선반, 드래그 이동, 진행률, 책 상세 | 동작하는 서재 |
| 3. 책 담기 | 알라딘 검색, 바코드, 직접 입력 | 실제 책 추가 |
| 4. 기록 | 담은 문장, 내 생각, 사진 OCR, 스와이프 | 기록 화면 |
| 5. 키즈 | 아이 서재, 읽은 횟수, 좋아요, 월별 그래프, 연속 주 | 키즈 모드 |
| 6. AI | 주간 추천, 추천 이유, 픽북스가 본 나, 머릿속 영역 분류 | 서버 + 연동 |
| 7. 배포 | GitHub Actions APK, 설치 안내 | 설치 파일 |

1~5단계는 AI·서버 없이 완결되는 MVP. 6단계는 키와 비용 결정 후 진행.

## 4. 위험·제약
- "이미지 그대로": 레이아웃·색·문구는 맞출 수 있음. 나무 책장 질감, 아이 방 일러스트, 머릿속 수채화 그림은 이미지 자산이 필요 → 컨셉 이미지에서 잘라 쓰거나 새로 그려야 함.
- 표지 이미지: 실제 책 표지는 API가 주는 URL을 표시만 함(앱에 내장하지 않음).
- AI 비용: 사용자 1명 주 1회 추천 + 월 1회 분석이면 월 수백 원 수준(정확한 단가는 모델 선택 후 계산).
- 키즈 머릿속 영역: 책→영역 분류 기준을 정해야 함(AI 자동 + 부모 수정 권고).
- 아동 개인정보: 아이 이름은 기기에만 저장.
- 플레이스토어 등록은 범위 밖(개발자 계정 25달러, 심사). 우선 APK 직접 설치.
